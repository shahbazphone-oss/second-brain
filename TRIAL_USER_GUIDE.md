# Second Brain - Trial User Guide

## 1) What is this app?
Second Brain is a simple personal notebook for saving ideas, notes, tasks, and important thoughts. It helps you:
- write notes quickly
- save ideas from your phone or computer
- find notes with search
- mark important notes
- add tasks
- connect related ideas
- use voice input and AI suggestions

This is designed for trial use before a full commercial version.

---

## 2) What you need
- A computer with internet
- Node.js installed
- A browser such as Chrome, Edge, Safari, or Firefox

### Install Node.js
Go to: https://nodejs.org/
- Download the LTS version
- Install it
- Restart your computer if needed

---

## 3) Quick setup
Open Terminal (Mac) or Command Prompt (Windows):

```bash
cd Desktop
git clone https://github.com/shahbazphone-oss/second-brain.git
cd second-brain
npm install
npm run dev
```

Then open this in your browser:

```text
http://localhost:3000
```

---

## 4) Main screen
You will see:
- Left side: notes list
- Right side: note editor
- Top bar: search, new note, export, import
- Bottom: pinned notes and tasks

---

## 5) How to create your first note
1. Click the blue button: New note
2. Add a title, for example: "My Business Idea"
3. Add tags, for example: business, idea, customer
4. Write your note in the text area
5. Click Save

### Example
Title: My Product Idea
Tags: product, idea, startup
Note:
"We should build a simple app for people to save daily learning notes."

---

## 6) Search and organize
Use the search box at the top to look for notes.

Examples:
- type "project" to find project notes
- type "customer" to find customer notes
- type "urgent" to see important work

### Tags help a lot
Use tags like:
- personal
- work
- idea
- project
- urgent
- review
- study

Good tags are short and specific.

---

## 7) Mark important notes
You can:
- Pin a note to keep it important
- Favorite a note to save it as a favorite

This helps you focus on what matters most.

---

## 8) Add tasks
1. Open a note
2. Go to Action queue
3. Add a task
4. Mark it done when complete

This is useful for:
- daily work
- study plans
- personal goals
- future action items

---

## 9) Connect related notes
If two notes belong together, link them.

For example:
- Note 1: "Customer feedback"
- Note 2: "Product improvements"

Link them to see connections and build a knowledge map.

---

## 10) Backup your notes
To protect your notes:
1. Click Export
2. Save the file on your computer
3. Keep it in a folder like Documents or Desktop

This is your backup file.

You can restore it later by clicking Import.

---

## 11) Voice recognition setup
For voice input, use the microphone button.

### Browser permissions
When you click the microphone, the browser may ask for permission.
Choose:
- Allow
- Allow access to microphone

### Supported languages
This app can be used with:
- English
- Urdu
- Punjabi
- Hindi

### Good speaking tips
- Speak clearly
- Keep your room quiet
- Speak at normal speed
- Say one idea at a time

### Example
Speak:
"I want to create a study app for students to save important notes and tasks."

The app should turn this into text, then you can edit and save it.

---

## 12) AI suggestions
AI can help by:
- suggesting better tags
- identifying related notes
- summarizing the note
- giving next-step suggestions

How to use:
1. Open a note
2. Click the Insight button
3. Review suggestions
4. Accept or ignore them

This helps you think faster and organize better.

## 13) Multilingual voice use
You can try speaking in:
- English
- Urdu
- Punjabi
- Mixed English + Urdu/Punjabi

## 15) Common problems
### App does not open
Run:
```bash
npm run dev
```
Then refresh the browser.

### Microphone not working
- Check browser permission
- Make sure the app is open in the browser
- Allow microphone access

### Notes not saving
- Refresh page
- Make sure you clicked Save
- Export notes as backup

### Voice not understanding properly
- Speak clearly
- Reduce background noise
- Try simpler sentences

---

## 16) Best practices
- Capture ideas immediately
- Use short tags
- Review pinned notes often
- Save backup files weekly
- Keep notes simple and clear
- Use AI suggestions to improve thinking
