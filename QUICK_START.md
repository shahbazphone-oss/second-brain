# Second Brain - Quick Start

## 1) Install and run
1. Install Node.js from https://nodejs.org/
2. Open Terminal (Mac) or Command Prompt (Windows)
3. Run:

```bash
cd Desktop
git clone https://github.com/shahbazphone-oss/second-brain.git
cd second-brain
npm install
npm run dev
```

4. Open this in your browser:

```text
http://localhost:3000
```

---

## 2) Create your first note
1. Click New note
2. Add a title
3. Add tags like:
   - work
   - idea
   - personal
   - study
4. Write your note
5. Click Save

Example:
- Title: Daily plan
- Tags: work, planning
- Note: "Finish customer research and review project tasks."

---

## 3) Find and organize notes
- Use the search box to find notes quickly
- Add tags to keep notes organized
- Pin important notes
- Favorite notes you want to revisit

---

## 4) Use tasks
1. Open a note
2. Add a task
3. Mark it done when complete

Use this for:
- work tasks
- study goals
- personal reminders
- ideas to review later

---

## 5) Backup your notes
1. Click Export
2. Save the file to your computer
3. Keep the file in a folder like Documents or Desktop

To restore later:
1. Click Import
2. Choose your saved file

---

## 6) Voice input
1. Click the microphone button
2. Allow microphone permission
3. Speak clearly
4. Review the text and save it

Good languages to try:
- English
- Urdu
- Punjabi
- Mixed language speaking

Tip: do not speak too fast and avoid background noise.

---

## 7) AI suggestions
1. Open a note
2. Click Insight or AI suggestions
3. Review the suggested tags or ideas
4. Accept or ignore them

This helps with:
- better note organization
- faster thinking
- related note discovery

---

## 8) Best practices
- Write ideas as soon as they appear
- Use short tags
- Save a backup every week
- Review pinned notes often
- Keep notes simple and clear

---

## 9) Quick troubleshooting
### App not loading
Run:

```bash
npm run dev
```
Then refresh the browser.

### Microphone not working
- Allow browser microphone access
- Check your microphone
- Try a different browser if needed

### Notes not saving
- Click Save again
- Refresh the page
- Export your notes as backup

---

## 10) Final reminder
This app is meant to help you capture ideas, organize information, and keep your work in one place. For trial use, it is simple and easy to learn.

For stronger multilingual voice and AI features in the future, the next version can connect to a dedicated speech and AI service.
