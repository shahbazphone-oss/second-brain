# Second Brain

The mobile-first personal knowledge app for your iPhone.

## Features
- Create, edit, and delete notes
- Search by title, tag, or content
- Filter notes by tag
- Mobile-first layout optimized for iPhone Safari
- Add to Home Screen support via manifest
- Local storage for persistence on-device

## Run locally

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## Why this is iPhone-friendly
- Responsive layout
- Large touch targets
- Minimal visual clutter
- Works well in Safari
- Can be installed as a standalone app on iPhone using Add to Home Screen
